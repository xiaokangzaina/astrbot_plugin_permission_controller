# AstrBot 权限控制台

`astrbot_plugin_permission_controller` 是一个面向 AstrBot 管理者的权限控制插件。它用群聊、私聊、用户白名单、群聊黑名单和模型思考强度规则控制机器人是否可以进入模型调用流程。

当前版本把插件设置页恢复为独立的“权限控制台”前端：左侧选择群聊或私聊对象，中间编辑权限策略，右侧显示运行状态和音效模块。

## 功能

- 群聊权限：支持整群放行、指定用户放行、指定用户拒绝。
- 私聊权限：支持按 QQ 好友单独开启私聊调用。
- 管理员绕过：可配置管理员是否绕过群聊与私聊限制。
- 群聊黑名单：可禁止指定 QQ 用户在群聊中调用机器人。
- 思考强度：支持全局、群聊、群成员、私聊好友维度覆盖 `reasoning_effort`。
- 可视化设置页：群聊和私聊列表会显示配置状态，已配置对象以绿色高亮。
- 音效模块：内置按钮音效和独立背景音乐开关，二者互不影响。
- 默认背景音：下载后默认曲目为 `小k橘子 - 劫后余生.mp3`。
- 自定义背景音：可在设置页右侧上传音频，前端会记住用户选择。
- 天气卡片：优先使用浏览器定位，失败时回退到后端 IP 粗定位。

## 安装

下载 Release 压缩包后，确保目录名为：

```text
astrbot_plugin_permission_controller
```

把整个目录放入 AstrBot 插件目录：

```text
data/plugins/astrbot_plugin_permission_controller
```

然后重启 AstrBot，或在 AstrBot 插件管理页重新加载插件。

## 使用

1. 打开 AstrBot 插件设置页，进入“权限控制台”。
2. 左侧选择“群聊”或“私聊”列表。
3. 选择对象后，在中间区域编辑权限策略。
4. 点击“保存配置”写入当前对象配置。
5. 右上角可以分别控制按钮音效和背景音乐。
6. 右侧音效模块可以上传自定义背景音，也可以恢复默认曲目。

## 配置说明

### 群聊

- 开启整群放行：允许当前群整体调用机器人。
- 允许用户 QQ：每行一个 QQ 号，仅允许这些用户在当前群调用。
- 拒绝用户 QQ：每行一个 QQ 号，优先级高于放行规则。
- 群默认强度：给当前群设置默认模型思考强度。
- 成员强度规则：格式为 `用户QQ=high`，可填写 `low`、`medium`、`high`。

### 私聊

- 开启私聊调用：允许当前好友私聊机器人。
- 私聊思考强度：给该好友覆盖模型思考强度。

### 音效

背景音乐和按钮音效使用不同开关。关闭背景音乐后会持久化保存，刷新或重新进入设置页不会自动播放。按钮音效仍可独立保留。

自定义上传的背景音保存在浏览器本地 IndexedDB 中，不会写入服务器配置文件。恢复默认后会重新使用内置的《小k橘子 - 劫后余生》。

## 升级说明

从旧版本升级时，原有权限配置会继续保留。`v3.0.2` 修复了 `v3.0.1` 下载包误显示为“五合一融合控制台”前端的问题，并将发布包恢复为独立权限控制台页面。
