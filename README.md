权限控制器 v1.9.8

用途
控制 AstrBot 在 QQ 群聊和私聊中的调用权限。

主要功能
- QQ群列表自动读取机器人已加入的群。
- QQ用户列表自动读取机器人好友。
- 群聊支持全群放行。
- 群聊支持本群允许用户列表。
- 群聊支持本群禁止用户列表。
- 全群放行和本群允许用户互斥。
- 本群禁止用户优先级最高。
- 私聊支持 QQ 用户白名单。
- 前端页面支持配置插件调用能力。
- 插件列表采用勾选生效逻辑。
- 未勾选插件不生效。
- 隐藏前端专用配置字段，不在插件后端配置面板显示。
- 过滤部分冗余发送日志。

规则说明
全群放行开启时，整个群的 QQ 用户都可以调用。
本群允许用户开启时，只允许列表内 QQ 用户调用。
本群禁止用户开启时，列表内 QQ 用户不能调用。
本群禁止用户优先级高于全群放行和本群允许用户。
插件列表中勾选的插件生效，未勾选的不生效。

使用方法
1. 安装插件。
2. 重启或重载 AstrBot。
3. 打开插件配置页。
4. 在 QQ群 或 QQ用户 页面配置权限。
5. 保存配置。

注意事项
- 修改配置后建议重载插件。
- 平台白名单会自动同步必要的群号和用户号。
- 前端专用插件配置不在后端配置面板展示。
