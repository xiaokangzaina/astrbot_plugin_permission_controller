# AstrBot 权限控制台

AstrBot 权限控制台是一个面向 AstrBot 管理者的五合一融合插件。它以权限管理为核心，把权限控制、通用生图、安全审核、QQ群管和网页截图集中到同一个可视化控制台中，减少来回切换插件页面和重复配置的成本。

插件内部 ID 仍然是 `astrbot_plugin_permission_controller`，因此旧版权限控制器可以平滑升级；外显名称已更新为“权限控制台”。

## 核心能力

- 权限控制：管理整群放行、用户-群号放行、私聊白名单、群聊黑名单、管理员绕过和模型思考强度。
- 通用生图：在统一控制台中配置生图相关能力，并支持按当前群聊或私聊对象启用或关闭。
- 安全审核：管理群消息审核配置，审核模块只面向群聊对象。
- QQ群管：集中管理入群、退群、禁言、通知等群管理相关能力，群管模块只面向群聊对象。
- 网页截图：管理网页截图任务、窗口尺寸、等待时间、失败通知和投递对象。
- 可视化控制台：使用四列布局组织插件入口、对象列表、配置表单和运行状态。
- 外观设置：支持主题色、背景色、背景图/GIF、焦点位置、雾化效果和背景卡透明度。
- 背景音乐：内置默认曲目 `小k橘子 - 劫后余生`，用户可在控制台中独立开启或关闭 BGM。
- 按钮音效：按钮音效和背景音乐使用独立开关，互不影响，并会记住用户选择。
- 自定义背景音：可在右侧音效模块上传本地音频，刷新页面后继续使用用户选择的音源。

## 控制台结构

控制台按管理动作组织，而不是按配置文件字段堆叠。

第一列是功能模块入口，用来切换权限控制、通用生图、安全审核、QQ群管和网页截图。

第二列是对象列表，用来选择当前要配置的群聊或私聊。安全审核和QQ群管只对群聊生效，因此会自动过滤到群聊对象。

第三列是配置区。当前模块与当前对象相关的配置项会平铺展示，减少多级折叠菜单带来的查找成本。

第四列是状态、音效与外观区，用来查看运行状态、统计信息、音频状态、背景预览和页面外观设置。

## 对象级开关

通用生图、安全审核、QQ群管和网页截图都支持“当前对象启用”。

这个开关只影响当前选中的群聊或私聊。例如：

- 选择某个群聊后关闭通用生图，只会关闭这个群的生图能力。
- 选择某个私聊后关闭网页截图，只会关闭这个私聊对象的截图能力。
- 安全审核和QQ群管只显示群聊对象，避免在私聊场景中出现无效配置。

权限控制模块仍然按权限规则判断消息是否允许进入模型调用流程。

## 安装

下载仓库或发行版后，确保插件目录名为：

```text
astrbot_plugin_permission_controller
```

把整个目录放入 AstrBot 插件目录：

```text
data/plugins/astrbot_plugin_permission_controller
```

然后重启 AstrBot，或在 AstrBot 插件管理页面重新加载插件。

## 从旧版升级

从旧版权限控制器升级时，原有权限规则会继续保留。

如果你之前单独安装过下面四个插件，使用本融合版前请先删除或停用它们，避免重复响应或重复处理事件：

- `astrbot_plugin_general_raw_image_2026`
- `astrbot_plugin_group_aip_review`
- `astrbot_plugin_qqadmin`
- `astrbot_plugin_webpage_screenshot`

升级前建议备份 AstrBot 的插件目录和配置目录。升级后进入权限控制台检查一次群聊、私聊、截图任务、审核策略和群管规则是否符合预期。

## 常见使用方式

让某个群可以使用机器人：进入权限控制，选择群聊，把该群加入整群放行。

让某个人只在某个群能使用机器人：进入权限控制，选择对应群聊，把该用户加入用户-群号放行规则。

让某个私聊好友可以使用机器人：进入权限控制，选择私聊对象，把该好友加入私聊白名单。

关闭某个群的通用生图：切换到通用生图，选择这个群聊，关闭当前对象启用。

关闭某个私聊的网页截图：切换到网页截图，选择这个私聊对象，关闭当前对象启用。

开启某个群的安全审核：切换到安全审核，选择这个群聊，打开当前对象启用并检查审核策略。

调整页面观感：在右侧外观区修改主题色、背景色、背景图片/GIF、雾化效果和背景卡透明度。

开启默认背景音乐：点击控制台左侧动作区的 BGM 按钮，默认播放 `小k橘子 - 劫后余生`。开关状态会保存在本地，刷新页面后仍会保留用户选择。

关闭或开启按钮音效：点击控制台左侧动作区的音效按钮。按钮音效不影响背景音乐，背景音乐也不会影响按钮音效。

上传自定义背景音：在右侧音效模块点击“上传背景音”，选择本地音频文件。自定义音频会保存在浏览器本地 IndexedDB 中，不写入服务器配置文件；点击“恢复默认”会重新使用内置曲目。

## 运行时说明

权限控制规则会直接影响 AstrBot 对消息和模型调用的处理。

融合模块的对象级开关会在运行时拦截对应模块的事件处理或工具调用。关闭后，当前对象不会继续执行该模块能力。

带有定时、后台或全局性质的任务，如果没有明确的群聊或私聊上下文，可能仍会按照原模块逻辑运行。建议在对应模块中同时检查任务目标和投递对象。

插件会尽量保留用户手动维护的 AstrBot 平台白名单，只移除本插件历史同步过、但当前配置已经删除的 ID。

## 注意事项

- 不要同时启用融合版和被融合的四个独立插件。
- 安全审核只面向群聊。
- QQ群管只面向群聊。
- 上传的背景图片或 GIF 会保存在本插件的数据目录中。
- 如果外层插件卡片没有立刻更新名称或头像，请重载插件、重启 AstrBot，或清理插件管理页缓存。
- 如果前端页面没有刷新出最新样式，请重启 AstrBot 或清理浏览器缓存后重新打开配置页。
