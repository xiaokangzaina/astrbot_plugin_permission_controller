# AstrBot 五合一权限控制台

这是一个面向 AstrBot 管理者的融合插件。它以“权限控制器”的前端控制台为主界面，把下面五个插件的配置入口和运行状态集中到一个页面里：

- 权限控制器
- 通用生图
- 安全审核
- QQ群管
- 网页截图

融合后的目标是：少开页面、少找配置、按群聊或私聊对象直接管理功能是否启用，同时保留原有插件的核心能力。

## 适合谁使用

如果你的 AstrBot 同时使用权限白名单、生图、安全审核、QQ群管、网页截图等功能，并且希望在一个控制台里统一管理群聊和私聊对象，这个版本更适合你。

如果你只需要其中一个很简单的功能，也可以继续使用单独插件。但请不要同时启用本融合插件和那四个被融合的独立插件，否则可能出现重复响应、重复审核、重复截图或重复处理群管事件。

## 已融合的能力

权限控制器负责 AstrBot 的基础访问控制。你可以管理整群放行、指定用户在指定群中放行、私聊白名单、群聊黑名单、管理员绕过规则，以及不同对象的模型思考强度。

通用生图负责图片生成相关配置。融合控制台会显示它的配置区块，并支持按当前群聊或当前私聊单独启用或关闭。

安全审核负责群消息内容审核。它只面向群聊场景，所以切换到安全审核时，对象列表只显示群聊，不显示私聊。

QQ群管负责群管理相关功能，例如入群、退群、禁言、审核、通知等群聊管理能力。它只对群聊有意义，私聊对象中会显示为仅群聊。

网页截图负责网页截图和定时投递相关能力。融合控制台会集中展示截图任务、目标、窗口尺寸、等待时间、失败通知等配置，并支持按当前群聊或私聊单独启用或关闭。

## 控制台布局

控制台分为四列。

第一列是插件入口，用来切换权限控制、通用生图、安全审核、QQ群管、网页截图。

第二列是对象列表，用来选择当前要配置的群聊或私聊。安全审核和QQ群管主要服务群聊，因此会自动限制到群聊对象。

第三列是配置列表。这里不再使用多级折叠菜单，所有可配置项会直接平铺展示，减少点不开、找不到、层级错乱的问题。

第四列是状态和外观区。这里展示运行状态、统计卡片、背景上传、GIF 或图片预览、主题色、背景色、背景卡透明度等前端设置。

## 当前对象启用开关

通用生图、安全审核、QQ群管、网页截图都支持“当前对象启用”。

这个开关只影响第二列当前选中的对象。例如你选中了某个群聊，再关闭通用生图，那么只有这个群聊不能使用通用生图，其他群聊和私聊不受影响。

如果你选中了某个私聊对象，再关闭网页截图，那么只会关闭这个私聊对象的网页截图能力。

安全审核只显示群聊对象，因为它本身就是群消息审核功能。

QQ群管只对群聊生效，私聊对象不会启用群管能力。

## 外观和背景

前端控制台支持自定义色调。你可以通过调色盘调整功能按钮、背景色和背景卡颜色。

背景支持上传图片或 GIF。上传后会在控制台右侧预览，并作为控制台背景使用。

背景设置里可以调整焦点 X、焦点 Y、雾化效果和背景卡透明度。雾化拉到最低时，背景遮罩会接近透明；背景卡透明度用于控制四列液态玻璃卡片的透明程度。

这些外观设置会保存在插件数据目录中，重进前端后会继续生效。

## 安装方式

下载发行版 ZIP 后，解压得到 `astrbot_plugin_permission_controller` 文件夹。

把整个文件夹放到 AstrBot 的插件目录：`data/plugins/astrbot_plugin_permission_controller`。

如果你之前单独安装过下面四个插件，请先删除或停用它们：

- `astrbot_plugin_general_raw_image_2026`
- `astrbot_plugin_group_aip_review`
- `astrbot_plugin_qqadmin`
- `astrbot_plugin_webpage_screenshot`

然后重启 AstrBot，或在 AstrBot 插件管理页面重新加载插件。

## 从旧版升级

从旧版权限控制器升级时，原来的权限规则会继续保留。

从四个独立插件迁移到融合版时，建议先备份 AstrBot 的插件目录和配置目录。融合版已经内置这四个插件的功能，旧插件不要继续单独启用。

如果你之前在独立插件里维护了大量配置，请在升级后进入融合控制台检查一次对应区块，确认群聊、私聊、任务、审核、群管规则都符合预期。

## 常见使用方式

想让某个群可以使用机器人：进入权限控制，选择群聊，把该群加入整群放行。

想让某个人只在某个群能使用机器人：进入权限控制，选择对应群聊，把该用户加入用户与群聊的放行规则。

想让某个私聊好友可以使用机器人：进入权限控制，选择私聊对象，把该好友加入私聊白名单。

想关闭某个群的通用生图：切换到通用生图，选择这个群聊，关闭当前对象启用。

想关闭某个私聊的网页截图：切换到网页截图，选择这个私聊对象，关闭当前对象启用。

想开启某个群的安全审核：切换到安全审核，选择这个群聊，打开当前对象启用，并检查审核策略。

想调整页面观感：在右侧外观区修改主题色、背景色、背景图片、GIF、雾化和背景卡透明度。

## 运行时说明

权限控制器的群聊和私聊规则会直接影响 AstrBot 对消息的处理。

融合模块的当前对象启用开关会在运行时拦截对应插件的事件处理和工具调用。关闭后，当前对象不会继续执行该插件功能。

带有定时、后台、全局性质的任务，如果没有明确的群聊或私聊事件上下文，可能仍会按照原插件自身逻辑运行。建议在对应插件区块里同时检查任务目标和投递对象。

## 注意事项

不要同时启用融合版和被融合的四个独立插件。

安全审核只面向群聊。

QQ群管只面向群聊。

上传的背景图片和 GIF 会保存在本插件的数据目录中，卸载或清理数据目录前请自行确认是否还需要保留。

如果前端页面没有刷新出最新样式，可以重启 AstrBot，或清理浏览器缓存后重新打开配置页。
